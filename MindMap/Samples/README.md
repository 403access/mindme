# Sample imports

These files are small, valid examples of each supported format. Drag any of
them onto MINDME (or use **File → Import Conversations…**) to replace the demo
dataset with a real, editable library.

- `chatgpt-conversations.json` — ChatGPT export shape (`mapping` + `current_node`)
- `gemini-my-activity.json` — Google Takeout Gemini Apps activity
- `claude-conversations.json` — Claude export shape
- `generic-threads.json` — MINDME generic schema
- `opencode-sample.db` — a miniature OpenCode SQLite library (sessions + messages)

The samples are synthetic and contain no personal data.
