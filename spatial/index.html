MINDME SPATIAL
LOCAL-FIRST · WEBXR · QUEST 3

Your conversations,
as a constellation.

MINDME turns ChatGPT, Gemini, Claude, and OpenCode archives into a spatial map of sources, topics, and shared language. Nothing leaves this device: the library is parsed in the browser and stored locally.

Ships with the MINDME demo archive. Export a library from the macOS app (File → Export Library for Quest) and load it here.

In the headset

  • Point a controller or hand at the map.
  • Trigger / pinch selects a node and opens its inspector.
  • Left stick walks. Right stick snaps the view in 30° turns; push up/down to scale the map.
  • A / X recenters the map and panels in front of you.
  • Close on a panel dismisses the inspector or guide.

Your data

  • Export from the Mac with File → Export Library for Quest.
  • Press LOAD JSON in the Quest Browser, then ENTER VR.
  • The file is parsed on-device and stored in this headset's browser storage. Nothing is uploaded.
  • Region grouping, the word-cloud lenses, and topic reclassification stay on the macOS build.
